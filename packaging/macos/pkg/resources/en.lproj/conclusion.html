Strata Arkyo is installed and running

The Strata Arkyo icon is now in the menu bar, at the top right of the screen. It shows the server status and opens the web interface.

Open http://localhost:8090 to create the first (owner) account, then sign in.

To uninstall, open Applications ▸ Uninstall Strata Arkyo.
Server log: /Library/Logs/Arkyo/arkyo-server.log
